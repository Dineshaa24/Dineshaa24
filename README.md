## Hi, I'm Dinesh

AI/ML Engineer in Chennai. I build NLP, LLM and speech systems that run in production, mostly for voice bots and contact-centre automation.

Day to day that means intent classification models, speech-to-text pipelines that have to keep up with live calls, and LLM/RAG features served behind FastAPI on AWS. I started out in mechanical engineering, moved into data analytics, and have been working on applied AI since 2024.

### What I work on

- **NLP and intent detection** – TF-IDF and transformer classifiers, Sentence-BERT embeddings, two-stage (process → intent) routing
- **LLMs and RAG** – LangChain, OpenAI and open-source models, vector search on PostgreSQL with pgvector
- **Speech-to-text** – Whisper / whisper.cpp, NVIDIA Parakeet, Vosk, VAD and speaker diarization on 8 kHz call audio
- **Serving and MLOps** – FastAPI, Kafka, Redis, WebSockets, Docker, Kubernetes, GPU inference on AWS

### Tech I use

- **Languages:** Python, SQL
- **ML / DL:** PyTorch, TensorFlow, scikit-learn, Hugging Face Transformers
- **GenAI:** LangChain, RAG, prompt engineering, pgvector
- **Backend:** FastAPI, Flask, REST, WebSockets, Kafka, Redis
- **Infra:** Docker, Kubernetes, AWS (EC2, Lambda, S3, Aurora PostgreSQL)
- **Data:** Pandas, NumPy, MySQL, PostgreSQL, Power BI
